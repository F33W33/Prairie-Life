Prairie Life – 3D avatar portraits

This folder contains 20 individual WebP avatar portraits named avatar-01.webp through avatar-20.webp.

For the game integration, place this folder at the repository root as:
  assets/avatars/

The intended browser paths are:
  assets/avatars/avatar-01.webp
  ...
  assets/avatars/avatar-20.webp

All portraits are square 512x512 WebP images. Keep the filenames unchanged.
